# DataLens · 数据到洞察

这是“可视化导论”数据分析作业的静态网站源代码。DataLens 用一个浏览器内的分析工作台把 pandas 的常用思路变成可视化操作，内置默认数据，也支持 CSV、TSV、JSON 和 Excel 文件。

## 亮点

1. **自动洞察**：上传后根据字段类型生成地区、品类和月份洞察卡片。
2. **三方联动**：点击柱状图或拖动趋势图时间轴，数据表、指标和其他图表同步响应。
3. **数据健康**：显示完整度、重复值、类型一致性，并可进行缺失值填充、去重和数值标准化。
4. **可复现分析**：记录每一步操作，提供等价 pandas 代码，并支持导出分析轨迹。

## 使用

直接打开 `index.html`，或在当前目录启动静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。页面通过 CDN 加载 ECharts 和 SheetJS，联网时支持完整图表与 Excel 导入。

## 文件

- `index.html`：页面结构与双语文案。
- `styles.css`：深色侧栏、浅色画布和紫色数据视觉系统。
- `app.js`：数据加载、pandas-like 操作、图表联动、导出和双语切换。
- `default-data.csv`：备用演示数据。
- `video_script.md`：不超过 5 分钟的视频讲解稿。
